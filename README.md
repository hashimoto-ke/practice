# C# & ASP.NET Core MVC 学習ハンズオン教材

C# の基本構文から、Minimal API を使った Web の基礎、そして本格的な ASP.NET Core MVC のフォーム処理や Dependency Injection（依存性注入）までを段階的に学習できるハンズオン教材プロジェクトです。
VS Code および **GitHub Codespaces** での学習に対応しており、環境構築不要でブラウザだけで開始できます。

---

## 🚀 学習ロードマップ

本教材は以下の 5 ステップ（全9つのコードツアー）で構成されています。

### 📂 1. `01_ConsoleApp` (Step 1: コンソール・C#基礎編)
- **学ぶこと**: プログラムのエントリーポイント、変数・型（`int`, `string`, `bool` 等）、関数の定義、ブレークポイントを使ったステップ実行などのデバッグ手法。
- **ハンズオン**: 引き算メソッド（`Hikizan`）の作成、変数の宣言と出力。

### 📂 2. `02_MinimalWebApi` (Step 2: Web API の基本編)
- **学ぶこと**: Web サーバーの仕組み、Minimal API によるルーティング（URLと処理の紐付け）、クエリパラメータの受け取り。
- **ハンズオン**: `/hikizan` エンドポイントを実装し、引き算の結果を Web ブラウザに返す処理。

### 📂 3. `03_MvcCalculator` (Step 3: MVC の基礎編)
- **学ぶこと**: MVC（Model-View-Controller）パターン、コントローラーでのルーティングと `ViewBag` によるデータ受け渡し、Razor構文、`_Layout.cshtml` を使った共通レイアウト。
- **ハンズオン**: コントローラーでの引き算アクション追加、ビューへの描画、トップ画面からのボタン遷移追加、ナビゲーションメニューへのリンク追加。

### 📂 4. `03_MvcCalculator` (Step 4: 実践フォーム・オブジェクト指向編)
- **学ぶこと**: HTML フォーム（`<form>`）を介した POST 送信、`[HttpGet]` / `[HttpPost]` の使い分け、型安全な `ViewModel` の活用、Data Annotations による入力バリデーション、クラスとインスタンス生成（オブジェクト指向基礎）。
- **ハンズオン**: ViewModel へのバリデーション属性追加、入力画面でのエラーメッセージ表示。

### 📂 5. `03_MvcCalculator` (Step 5: Dependency Injection 編)
- **学ぶこと**: インターフェース（`ICalculatorService`）の活用による「責務の分離」と「疎結合化」、コンストラクタ注入（DI）、DIコンテナへのサービス登録。
- **ハンズオン**: サービスの DI コンテナ追加（`AddScoped`）、コンストラクタインジェクションの実装、計算ロジックのサービス移管。

## 📖 進め方

### 💻 パターン A: ローカル環境で実行する場合

#### 前提条件
1. **[.NET SDK 10.0 以降](https://dotnet.microsoft.com/download)** をインストール
2. **[Visual Studio Code](https://code.visualstudio.com/)** をインストール
3. VS Code 拡張機能 **C# Dev Kit** と **CodeTour** をインストール

#### 手順

1. **リポジトリをクローンして VS Code で開く**:  
   ターミナル（またはコマンドプロンプト）を開き、保存したいフォルダに移動して以下を実行します：
   ```bash
   git clone <リポジトリのURL>
   cd <リポジトリのフォルダ名>
   code .
   ```

2. **CodeTour を開始する**:
   - アクティビティバー（左端のアイコン一覧）にある「**エクスプローラー（Explorer）**」のアイコンをクリックします。
   - サイドバー下部にある「**CodeTour**」パネルを展開します。
   - 学習したいツアー（初めての方は 01: Console App Basics）を選び、右側に表示される再生ボタン（▶）をクリックするとガイドが始まります。

### ☁️ パターン B: GitHub Codespaces を使う場合（環境構築不要）
パソコンへのソフトのインストールや設定が不要で、ブラウザだけで学習を開始できます。

#### ⚠️ Codespaces 利用時の注意点
   - **初回起動に数分かかります**: .NET 環境や VS Code 拡張機能を自動でセットアップするため、画面が立ち上がるまでに時間がかかる場合があります。そのまま少々お待ちください。
   - **一定時間操作がないと自動停止します**: デフォルトでは **30 分間無操作** が続くと、サーバー費用節約のため自動的に停止（休止）状態になります。再度開くことで作業を再開できます。
   - **通信環境の影響を受けます**: ブラウザ上で動くため、ネット接続が不安定になるとコードの保存や動作確認が重くなる場合があります。
   - **無料利用枠があります**: GitHub 無料アカウントの場合、Codespaces には **月 120 時間（コア時間）の無料枠** が設定されています。学習が終わったらブラウザのタブを閉じるか、Codespaces を停止（Stop）する癖をつけておくと安心です。

#### 手順

1. **Codespace を起動する**:
   - 本リポジトリの GitHub ページ上部にある緑色の「**<> Code**」ボタンをクリックします。
   - 「**Codespaces**」タブを選択し、「**...**（三点リーダー）」>「**New with options...**」をクリックします。
   - Machine type で **4-core**（または 2-core）を選択し、「**Create codespace**」をクリックします。  
      * **サクサク動かしたい方は「4コア」がおすすめ！**:
      標準（2コア）でも動作しますが、**4コア** にすると起動やプログラムの実行速度が大きく向上します。  
      ※コア数を増やすと、その分月間の無料枠の消費ペースが早くなる点だけご留意ください
   - 数分待つと、ブラウザ上で VS Code 環境が立ち上がります（必要な環境は自動的に準備されます）。

2. **CodeTour を開始する**:
   - 起動完了後、画面左側のアクティビティバーにある「**エクスプローラー（Explorer）**」のアイコンをクリックします。
   - サイドバー下部にある「**CodeTour**」パネルを展開します。
   - 学習したいツアー（初めての方は 01: Console App Basics）を選び、右側に表示される再生ボタン（▶）をクリックするとガイドが始まります。
